# FIGURE SOURCING AND REFERENCING POLICY

Every suggested figure must include:

1. Figure description.
2. Source classification.
3. Proper citation method.
4. Recommended caption format.

Never suggest a figure without specifying its source category.

---

# Figure Source Categories

All figures must belong to one of the following categories.

---

## Case 1: Adapted from a Reference

Use when a figure is largely based on a textbook, paper, or external source and only minor modifications are made.

Format:

**Suggested Figure X.X:** Figure description.

**Source:** Adapted from [CIT-TSE] / [CIT-LUO] / [CIT-GOLUB].

**Caption Example:**

> Figure X.X: Figure description (adapted from [Ref. XX]).

Examples:

* MIMO system model
* Equalizer block diagrams
* Cholesky decomposition concepts

---

## Case 2: Redrawn by the Author Based on a Reference

Preferred whenever possible.

Use when the original idea comes from a reference but the figure is completely redrawn using the thesis style.

Format:

**Suggested Figure X.X:** Figure description.

**Source:** Redrawn by the author based on [CIT-TSE] / [CIT-LUO] / [CIT-GOLUB].

**Caption Example:**

> Figure X.X: Figure description (redrawn by the author based on [Ref. XX]).

This is generally the preferred approach for thesis writing.

Examples:

* MIMO receiver chain
* Equalization flow
* Matrix reformulation diagrams

---

## Case 3: Author's Work

Use when the figure is derived entirely from:

* project architecture,
* project algorithms,
* RTL architecture,
* hardware pipeline,
* latency analysis,
* simulation results,
* system integration work.

Format:

**Suggested Figure X.X:** Figure description.

**Source:** Author's work.

**Caption Example:**

> Figure X.X: Figure description.

No external citation is required.

Examples:

* Proposed equalizer flow
* HWPE architecture
* FFT pipeline
* Latency schedules
* Performance comparison figures
* Integration diagrams

---

## Case 4: Adapted from Multiple References

Use when the figure combines ideas from more than one source.

Format:

**Suggested Figure X.X:** Figure description.

**Source:** Adapted from [CIT-TSE] and [CIT-LUO].

**Caption Example:**

> Figure X.X: Figure description (adapted from [Ref. XX] and [Ref. YY]).

Examples:

* Combined equalization flow
* Detection and equalization processing chains
* Hybrid algorithm illustrations

---

# Preferred Figure Strategy for This Thesis

Whenever possible:

1. Redraw figures instead of copying them.
2. Create project-specific figures.
3. Use author-generated diagrams.
4. Minimize direct reuse of textbook graphics.

This produces a more professional thesis and avoids copyright concerns.

---

# Figure Usage Workflow

Whenever suggesting a figure, always provide:

```text
Suggested Figure X.X: <Description>

Source:
- Author's work
or
- Adapted from [CIT-TSE]
or
- Adapted from [CIT-LUO]
or
- Adapted from [CIT-GOLUB]
or
- Redrawn by the author based on ...

Caption Example:
Figure X.X: ...
```

Never omit the source classification.
